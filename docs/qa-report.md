- Chromium 140 E2E 11개 통과: 생성·배정·잠금·불참·재배정·확정·JSON 복원·출력·다중 탭·저장 실패·Worker 취소.

이는 공개 이전 로컬 결과입니다. 생성된 검증 산출물은 공개 Git 이력에 넣지 않습니다. `npm test`, `npm run build`, `npm run test:e2e`로 재현하며 산출물은 Git에서 제외한 `docs/qa/`, `work/`에 생성됩니다. 계산 검증 범위는 [테스트 매트릭스](qa/core-test-matrix.md)에 있습니다.

## 공개 URL 검증 실행

배포 후 `PUBLIC_BASE_URL=https://erakeun.github.io/event-timetable-maker/ npm run test:e2e`로 실제 공개 정적 파일을 검증할 수 있습니다. 로컬 서버는 실행하지 않습니다. 각 테스트는 격리된 브라우저 저장소와 가상 데이터만 사용합니다.

Safari·Firefox·실제 휴대폰·실물 프린터·Excel 앱 시각 검수는 미검증입니다. 배정은 휴리스틱이며 전역 최적성을 보장하지 않습니다. XLSX 라이브러리로 인한 청크 크기 경고는 남아 있습니다.
