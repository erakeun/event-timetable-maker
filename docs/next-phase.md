# 후속 범위 — 현재 V1에 포함하지 않음

현재 제품은 브라우저 로컬 편집과 출력/파일 전달만 제공한다. 실시간 공동 편집, 온라인 가능시간 수집, 이메일·카카오 알림, 개인별 조회 링크/QR, 급여·정산·인증·출퇴근, OCR·외부 캘린더·AI 채팅을 구현하거나 동작하지 않는 버튼으로 노출하지 않는다.

온라인 수집·협업이 필요한 후속 버전은 다음을 별도로 설계하고 검증한다.

- 기본 로컬 모드를 유지하고 행사별로 공유를 명시적으로 선택할 때만 독립 백엔드를 사용한다.
- 편집자 인증, 행사별 권한, 참여자 본인의 가능시간 수정권한, 조회 전용 공개본을 분리한다.
- 임의 추측이 어려운 토큰은 한 요소일 뿐이다. 서버에서 매 요청 권한검사, 토큰 만료·폐기·회수, 변경 범위, 요청 제한과 데이터 삭제를 집행한다.
- 다른 행사 데이터 읽기/쓰기 차단, 소유자 변경, 만료·회수, IDOR, 공개 필드 최소화와 삭제 정책을 테스트한다. 공개본에는 명시적으로 선택한 항목만 담는다.
- 이름·명단·운영자 메모를 URL 쿼리/fragment에 넣지 않는다. HTML 속 비밀번호나 전체 공개 Firestore 규칙은 사용하지 않는다.
- 다중 기기 충돌 해결, 서버 revision, 오프라인 변경 동기화는 로컬 CAS와 별도 설계한다. 현재 수정기록을 위변조 방지 감사로그로 취급하지 않는다.
- 배포 서비스·가격·과금·보관 기간은 실제 선택 시 확인하고 승인받는다. 이번 구현에서는 클라우드 자원이나 유료 API를 생성하지 않았다.

선택 링크를 통한 명패·안내문 도구 연결은 공개 주소 확인까지만 진행했다. 자동 데이터 전달은 양쪽 앱의 명시적 인터페이스·허용 범위를 확인한 다음 별도 작업으로 구현한다.
