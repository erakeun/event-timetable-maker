# 핵심 계산 검증 기록과 요구사항 매핑

실행 명령: `npx vitest run tests/core-engine.test.ts tests/performance-engine.test.ts --silent=false`

## 별도 기준으로 대조한 작은 문제

행사09:00~10:00, 단일 장소/역할, 필요1명, 사람A/B, 최소·권장30분 문제다. A의 전반/후반과 B의 전반/후반 가능 여부 네 비트를 모두 열거하여 `2^4=16`개 문제를 만든다. 각 문제의 후보 배정은 전반과 후반 각각 `{미배정, A, B}`이며, `3^2=9`개 조합을 계산한다. 비트상 불가능한 사람을 넣은 조합은 제외하고, 나머지의 실제 충족 분 합계 최대값을 구한다. 이 기준은 엔진·검증기·`availabilityState`를 사용하지 않는다.

자동배정의 충족 분을 그 최대값과 비교한다. A전반/B후반만 가능한 경우에는60분, B가 불가인 별도 회귀 사례에는30분을 기대한다. 이는 이 작은 문제 군에 대한 정답 대조이며 일반 문제에서 전역 최적해를 찾는다는 증거가 아니다. 큰 문제의 탐욕적 선택은 충분한 인원이 있어도 빈틈을 남길 수 있다.

## 무작위 독립 오라클

- **100회, seed20261010:** 0~6명, 필요1~3명, 임의 가능 경계·개인전체상한·연속60분·휴게15분. 생성된 결과를 1분마다 직접 순회하여 필요 인원 초과, 동일인 중복, 원시 가능 구간 밖 배정이 없는지 확인한다. 사람별 시간을 직접 더하고 인접 근무 간격·연속합계를 계산한다.
